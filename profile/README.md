# DataYoga

Open-source data tools.

| Project | What it does |
|---|---|
| [tracemodel](https://github.com/datayoga-io/tracemodel) | Traced, checked financial models in Python. Every number has an address, a source, and rules that check it. `pip install pytracemodel` |
| [datayoga](https://github.com/datayoga-io/datayoga) | A framework to build and run streaming or batch data pipelines, defined in YAML. |
| [lineage](https://github.com/datayoga-io/lineage) | Generates documentation and data lineage charts for data pipelines. |
